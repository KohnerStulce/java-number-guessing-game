# Java Number Guessing Game

This is a number guessing game I made in Java to practice using loops, conditionals, and user input.

The program picks a random number between 1 and 100, and the player has to guess what it is. After each guess, the program tells the player if their guess is too high or too low until they get the correct number.

## Features

- Generates a random number from 1 to 100
- Lets the player enter guesses
- Tells the player if their guess is too high or too low
- Continues until the correct number is guessed

## What I Used

- Java
- Random class
- Scanner for user input
- While loops
- If-else statements

## How to Run

1. Make sure Java is installed.
2. Open a terminal in the project folder.
3. Compile the program:

   `javac src/Main.java`

4. Run the program:

   `java -cp src Main`

## About

I made this project to get more practice with Java and become more comfortable writing programs without following a full tutorial.
